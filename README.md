# URL Shortener

A URL shortener built using Node.js, Express.js, MongoDB, Mongoose, and Nanoid.
This project generates unique short IDs for URLs and stores the URL records in a MongoDB database.

## Features

- Generate unique short IDs using Nanoid.
- Accept URLs through HTTP requests.
- Store URL records in MongoDB.
- Use Express.js to handle HTTP requests.
  
## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- Nanoid
